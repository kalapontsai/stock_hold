# stock_hold Wireframe — Phase 2 設計輸入

> 本文件為 **Phase 3（frontend-developer）** 的設計輸入；所有方框為 **語意元件** 而非視覺 mock，
> 表格/卡片內的數字皆為 **示意值**，請以 SPEC §1.1 實體欄位為準。
> 全部 5 個核心頁面各提供 **桌機（≥1024px）** 與 **手機（≤640px）** 兩種 layout。

---

## 0. 共用規範

### 0.1 框圖符號
| 符號       | 意義                                        |
| ---------- | ------------------------------------------- |
| `═══`      | Sticky header / 頂部列                       |
| `───`      | 區塊分隔線 / 表頭底線                        |
| `[ btn ]`  | 可點擊按鈕                                  |
| `< input >`| 輸入欄位                                    |
| `{ sel }`  | 下拉選擇                                    |
| `▓ ░`      | 進度條 / 圖表填充                           |
| `▶`        | 摺疊 / 展開                                 |
| `↑ ↓ ▲ ▼` | 漲跌箭頭（紅跌綠漲，台灣慣例已翻轉為紅漲綠跌）|
| `🌓`       | 主題切換                                    |
| `≡`        | 漢堡選單                                    |
| 角落標 `①` | 註腳編號（文末統一說明）                    |

### 0.2 螢幕寬度分界
| 區段       | px         | 用途                            |
| ---------- | ---------- | ------------------------------- |
| Compact    | ≤ 640      | 手機（直/橫），主標的一欄流      |
| Medium     | 641–1023   | 平板，兩欄佈局                   |
| Expanded   | 1024–1439  | 桌機標準，sidebar + 多欄 grid    |
| Wide       | ≥ 1440     | 桌機寬螢，metric card 4-up+      |

### 0.3 全域殼層（AppShell）
桌機永遠使用左側 sidebar；手機使用底部 tab bar。
header 上的「更新市價」按鈕與「最後更新時間」為 Phase 3 必須實作（觸發 `POST /api/v1/prices/batch-update`）。

⑤ 月度損益預設 **bar chart**（stacked = 已實現 + 未實現）；Y 軸 NT$ 自動縮放。

#### 互動細節
- 儲存按鈕：必填通過 → 啟用；按下後 spinner 顯示 200ms+，避免 double submit。
- 編輯模式：modal 標題變「編輯交易」、「刪除」按鈕出現於左下，並請求 `ConfirmDialog`。
- 欄位切換：type 變更會把 amount_per_share / 股利欄位重新組裝；Phase 3 不要做「智慧記憶」，重置即可。
- 錯誤處理：API 回 `VALIDATION_ERROR` 時，欄位下方出現紅字 + `aria-invalid="true"` + `aria-describedby`。

## 6. 共用互動細節（給 Phase 3 一致性指引）

### 6.1 載入狀態
- 表格資料載入：使用 `LoadingSkeleton`（5–8 列灰階佔位）。
- 卡片載入：高度不變，內部 60% 透明 shimmer。
- 按鈕按下後 spinner + disable，不可重複觸發。

### 6.2 空狀態（EmptyState）
- Holdings 無持倉：插圖（簡單 SVG 撲滿）+「目前沒有持倉，先到 Transactions 新增一筆 BUY 吧！」+ 主按鈕。
- Transactions 無資料：「這段時間沒有交易」+「清除篩選」次按鈕。
- Dashboard 首次登入：「歡迎！讓我們從建立第一個帳戶開始」+主按鈕。

### 6.3 錯誤狀態
- API 5xx：頂部紅色 toast「資料載入失敗（503），5 秒後重試」+自動 retry 一次。
- 401/403：modal「請重新設定 API token」+跳轉 Settings。
- 網路斷線：右下角持續顯示「離線模式（資料可能過時）」。

### 6.4 a11y 細節（與 §DESIGN-TOKENS 一致）
- 全部互動元件可 **純鍵盤操作**（Tab、Enter、Esc、方向鍵）。
- Modal：focus trap + Esc 關閉 + 開啟時把焦點移到第一個輸入框。
- 表格：`<table>` + `<caption>` + `<th scope>` + 每行 `<tr tabindex="0">` 可單獨 focus（編輯捷徑）。
- 顏色不是唯一資訊載體：漲跌同時用 `▲▼` 箭頭 + `+`/`-` 文字；狀態 badge 同時有 icon。
- focus ring 永遠可見：`outline: 2px solid var(--color-primary-500); outline-offset: 2px;`。

### 6.5 響應式策略
- Mobile first：CSS Grid + flex；桌機版 sidebar 改為 fixed position，main 內容加 `padding-inline-start: 280px`。
- 表格 → 卡片：在 ≤ 640px 下，DataTable 自動轉為「卡片串列」模式（每列變成 §3.2 那種卡片）；此為 component-level responsive，**不是 hidden md:block**。
